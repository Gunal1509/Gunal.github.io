📂 Installation

Clone the repository:

git clone https://github.com/gunal1509/Gunal.github.io.git

Navigate to the project folder:

cd Gunal.github.io

Install dependencies:

npm install

Run the development server:

npm run dev
📦 Build Project
npm run build
