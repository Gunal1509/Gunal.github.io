## 📂 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Gunal1509/Gunal.github.io.git
   cd Gunal.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Production Build**:
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages**:
   ```bash
   npm run deploy
   ```
